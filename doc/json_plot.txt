1. INTRODUCTION                                      *json-plot-introduction*

json-plot.nvim renders interactive ASCII Gantt charts from JSON data
files. Define multiple plot series with a fluent Lua config API, each with
its own data source, field mappings, colors, and tags.

Primary use case: medical/pharmacy data analysis (admissions, prescriptions,
care coordination timelines).

==============================================================================
2. COMMANDS                                              *json-plot-commands*

                                                                    *:JsonPlot*
:JsonPlot {data.json} [{config.lua}]
    Open a timeline chart from a JSON data file. If {config.lua} is not
    provided, looks for `.json_plot.lua` or `.tsdb_plot.lua` in the same
    directory as the data file, or falls back to interactive field selection
    via |vim.ui.select|.

                                                              *:JsonPlotReload*
:JsonPlotReload
    Hot-reload all plugin modules. Clears Lua module caches and re-requires
    all json_plot modules. Use during development to pick up code
    changes without restarting Neovim.

3. CONFIGURATION                                    *json-plot-configuration*

Call `setup()` in your init.lua: >lua
    require("json_plot").setup({
      -- optional overrides
    })
<

For lazy.nvim local development: >lua
    {
      dir = "~/git/neovim-json-visualizer",
      config = function()
        require("json_plot").setup()
      end,
    }
<

==============================================================================
4. CONFIG FILE API                                    *json-plot-config-api*

Create a `.json_plot.lua` file alongside your JSON data: >lua

    local tl = require("json_plot.builder")

    tl.title("My Timeline")
    tl.sort("start")

    tl.plot("medicalHistory")
      :label("facility")
      :start("admitDate")
      :end_date("dischargeDate")
      :tag("Admission")
      :color("#e06c75")

    tl.plot("prescriptions")
      :label("drugName")
      :start("fillDate")
      :end_computed("fillDate", "daysSupply")
      :tag("Rx")
      :color("#98c379")
<

Plot methods (all return self for chaining):
  :label({field})           String field name or function(entry)->string
  :sublabel({field})        Secondary label appended in parentheses
  :start({field})           Start date field name
  :end_date({field})        Explicit end date field name
  :end_computed({s},{d})    End = entry[s] + entry[d] days
  :end_computed_expr({fn})  End = start + fn(entry) days
  :tag({name})              Series tag (shown as [Tag] prefix)
  :color({hex})             Hex color for bars (e.g., "#e06c75")
  :filter({fn})             Predicate function(entry)->boolean

Global methods:
  tl.title({string})        Chart title
  tl.sort({order})          Default sort: "start", "end", "duration", "label"
  tl.date_format({fmt})     Date parsing format

==============================================================================
5. KEYBINDINGS                                        *json-plot-keybindings*

These keybindings are active only in the chart buffer:

  q         Close the chart
  + or =    Zoom in (increase time resolution)
  -         Zoom out (decrease time resolution)
  s         Cycle sort order (start↑, start↓, end↑, duration↓, label)
  f         Filter by date range (prompts for start/end)
  F         Filter by tag/series (picker)
  r         Reset all filters and zoom
  <Enter>   Show full JSON details of entry under cursor
  ?         Show keybinding help
